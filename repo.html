Versiones

Son las versiones normales de la aplicación con soporte completo para las últimas características de Android y del Server.

Las versiones estan organizadas por Title Update representando las principales actualizaciones de la aplicación.

Necesitas Android 8.0 Oreo (API 26) como mínimo para ejecutar estas versiones.

En futuras actualizaciones, se necesitara Android 10 (API 29) para seguir utilizando estas versiones.

Versiones Lite

Las versiones Lite son versiones más ligeras y optimizadas para versiones antiguas de Android.

Están diseñadas para funcionar en dispositivos con recursos limitados, ofreciendo una experiencia más fluida y rápida.

Necesitas Android Alpha (API 1) como mínimo para ejecutar la Title Update 2.

Es recomendable utilizar Android 4.2 Jellybean (API 17) para evitar problemas de seguridad

  • Title Update 1 (TU6 - 1.4) 72KB Ver
